# Episode 01 Demo — 执行与验收规格

## 目标

把第一集从“驾驶到光圈”的技术原型，升级为一段 5–7 分钟、可由 3–10 岁儿童独立完成的互动故事。孩子在不被考试感打断的前提下，理解 `SCHOOL`、`FAST`、`SLOW`、`LOOK OUT`、`HELLO`，并体验礼让、观察、表达不安和主动交友。

## 六段体验

| 段落 | 玩家行为 | 剧情反馈 | 学习点 | 安全兜底 |
|---|---|---|---|---|
| 01 入校 | 沿蓝灰色道路前进 | Eddy 说第一次上学 | FIRST DAY | 路面箭头和目标方向提示 |
| 02 揭示 | 驶过校门 | 镜头抬升展示学校 | SCHOOL | 短暂锁定驾驶，镜头结束自动恢复 |
| 03 礼让 | 靠近横穿的长车 | 引导先观察再通过 | SLOW / LET IT PASS | 危险距离内自动减速，无碰撞失败 |
| 04 快车 | 穿过停车场入口 | 快车掠过，Eddy 吓一跳 | FAST / LOOK OUT | 快车经过时自动限制车速 |
| 05 情绪 | 驶入安静轮胎角落 | Eddy 表达自己不够快的担心 | 识别和表达情绪 | 低速自动泊停，不要求精确压线 |
| 06 问候 | 选择一句英文回应 Poppy | 两位角色建立友谊 | HELLO / I'M EDDY | 两个答案都正确、都能完成故事 |

## 驾驶标准

- 相机保持低位、跟车、缓动，不使用快速甩镜或持续震动。
- 前进最高速度受限；倒车更慢；松开按键自然减速。
- 转向随车速渐进，原地不能高速旋转。
- 安全制动只在危险窗口显示，提示为 `SAFE & SLOW / 安全减速中`。
- 不出现生命值、星币、失败弹窗、倒计时和排行榜。

## 视觉标准

- Eddy 始终为高饱和蓝色，是画面第一视觉焦点。
- 校园使用奶油色、珊瑚色和柔和绿色，避免程序化纯色方块感。
- 道路、路缘、停车线、建筑和轮胎角落共同完成空间导视；不使用悬浮光圈。
- UI 只保留目标胶囊、声音、暂停、字幕和必要的触屏控制。
- 游戏镜头内 HUD 面积不超过约 15%，不遮挡 Eddy 和路口来车。

## 桌面与触屏验收

- 1366×768：目标、字幕、右上角按钮互不遮挡。
- 390×844 竖屏：可以启动和阅读，但建议设备旋转为横屏完成驾驶。
- 844×390 横屏：触屏方向键和踏板不覆盖字幕或危险道路。
- 键盘和触屏按钮松开后必须立即清除输入状态。
- 页面切到后台时自动暂停，回到页面后由家长或孩子主动继续。

## 阶段 2 完成定义

- `pnpm typecheck` 通过。
- `pnpm build` 通过，Cloudflare 输出目录为 `dist`。
- 六段状态机能按顺序触发，两个问候选项都进入完成页。
- 浏览器控制台无项目运行错误；若设备不支持 WebGL，显示可理解的硬件加速提示。
- 本阶段推送到 `redesign/episode-01`，不直接合并 `main`。
