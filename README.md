# Tire Town Learning Adventure — 3D Demo

一个围绕《Tire Town School》前 5 集设计的儿童 3D 英语学习游戏概念 Demo。它不是视频播放器，而是把动画中的情境变成孩子可以驾驶、探索和完成的任务。

## 已实现

- 5 个可选择、可完成的 3D 故事场景
- 键盘与手机触屏驾驶
- 中英双语任务、情境对话和英文语音朗读
- 单词收集、步骤反馈、关卡星星和本地进度保存
- 无失败惩罚的儿童友好流程
- 不依赖外部 3D 模型的低多边形概念美术

## 本地运行

```bash
pnpm install
pnpm dev
```

打开终端显示的本地地址。桌面端使用 `WASD` 或方向键驾驶、空格键鸣笛；触屏端使用画面下方按钮。

生产构建：

```bash
pnpm build
```

构建结果在 `dist/`。
